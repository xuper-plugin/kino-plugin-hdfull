# HDFull para Kino

Plugin de [Kino](https://kinotvapp.github.io/kino-plugins/) con películas y series de HDFull que se ven
sin captcha: solo copias en Vidmoly, Streamtape y Mixdrop. Las copias en servidores con captcha
(Powvideo, Streamplay, Waaw) no se muestran.

- Títulos, pósters, resúmenes y nombres de episodios salen de TMDB, a través de Kino.
- Idioma preferido en los ajustes: castellano, latino o subtitulado. Las demás copias quedan en el menú Servidor.
- Si una copia ya no existe en el servidor, el plugin la descarta al vuelo; un título sin copias vivas sale de las listas.

## Instalar

En Kino aparece en **Plugins → De la comunidad**: toca Actualizar y busca "HDFull".

También puedes agregarlo por URL pegando:

```
https://raw.githubusercontent.com/xuper-plugin/kino-plugin-hdfull/main/kino-plugin.json
```
